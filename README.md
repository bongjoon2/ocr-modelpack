# OCR 모델팩 (Korean OCR Model Pack)

파일변환스튜디오용 한국어 OCR 모델입니다.

## 다운로드

[ocr_모델팩.zip (22MB)](https://github.com/bongjoon2/ocr-modelpack/releases/download/v1.0/ocr_.zip)

## 설치

1. 위 링크에서 다운로드
2. 압축 해제
3. `ocr_models` 폴더를 실행 파일(`FileConverter.exe`)과 같은 폴더에 넣기

```
FileConverter.exe
ocr_models/
  ├── korean_rec.onnx
  └── korean_dict.txt
```

## 라이선스

- 모델: PaddleOCR PP-OCRv4 (Apache 2.0)
- 재배포: Apache 2.0 라이선스 하에 가능
